# **App Name**: StrikeLearning

## Core Features:

- Course Listing and Details: Display available courses with detailed descriptions, schedules, and enrollment options.
- Community Event Timeline: Show a timeline of upcoming community events and workshops.
- Personalized Learning Paths: AI powered system creates learning path that aligns with your goals and adjusts based on performance, acting as a tool that makes recommendations and monitors progress.
- Progress Tracking: Allow users to track their progress in each course.
- Email Notifications: Send email notifications for course updates, event reminders, and account-related information.
- Contact Form Submission: Enable users to send messages via a contact form.

## Style Guidelines:

- Primary color: Red (#FF3B3B), echoing the brand's energetic identity.
- Background color: Dark gray (#0B0505) to give a premium look.
- Accent color: Pink-red (#FF7B7B) to complement the primary color.
- Body and headline font: 'Poppins', a geometric sans-serif font, should be used for a contemporary and fashionable feel.
- Use sharp, modern icons to represent different courses and features.
- Maintain a clean and structured layout with clear sectioning for easy navigation.
- Incorporate subtle animations for a smooth user experience.
